# hugolify-theme-events-persons

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-events-persons` module:

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-events-persons
  - path: github.com/hugolify/hugolify-theme-events
  - path: github.com/hugolify/hugolify-theme-persons
  - path: github.com/hugolify/hugolify-theme
```
